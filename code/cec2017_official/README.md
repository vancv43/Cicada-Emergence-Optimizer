# Official CEC2017 code

`cec17_test_func.cpp` and `input_data/` are the unmodified official files of the CEC2017 bound-constrained competition, github.com/P-N-Suganthan/CEC2017-BoundContrained. `cec2017_official.py` builds `libcec17.so` from `wrap.cpp` with `clang++` or `g++` on first use; a C++ compiler is therefore required.
